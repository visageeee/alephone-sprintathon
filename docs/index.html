Installation help
Linux

With Flatpak installed, open a terminal in your download folder:

flatpak install --user --reinstall ./Sprintathon-20260924-0031-x86_64.flatpak

Launch from your application menu or run:

flatpak run --branch=stable io.github.visageeee.Sprintathon
Windows

Extract the complete ZIP and run Sprintathon.exe. Keep the accompanying folders together. Builds are unsigned; see the Windows guide for first-launch help.

macOS

Extract the ZIP and move Sprintathon.app into Applications. Builds are unsigned and not notarized; see the macOS guide for first-launch help.

Need scenario data or other help? Read the full guide.
